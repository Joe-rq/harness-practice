## 编码系统

### ICD-10 诊断编码

**结构**: `字母 + 数字 + . + 数字`

示例: `J18.9` (肺炎)

| 章节 | 范围 | 分类 |
|------|------|------|
| I | A00-B99 | 传染病和寄生虫病 |
| IX | J00-J99 | 呼吸系统疾病 |
| X | K00-K95 | 消化系统疾病 |
| XVII | S00-T98 | 损伤、中毒等 |

### ICD-9-CM-3 手术编码

**结构**: `数字 . 数字`

示例: `45.13` (胃镜检查)

| 章节 | 范围 | 分类 |
|------|------|------|
| 1 | 0-17 | 手术 |
| 2 | 18-31 | 产科手术 |
| 3 | 32-86 | 内科手术 |

## DRG 分组

### 基本原理

1. **主要诊断** → MDC (25个)
2. **手术/操作** → ADRG (约400个)
3. **合并症/并发症** → DRG (约700个)

### 分组流程

```
患者入院
    ↓
主要诊断 (ICD-10)
    ↓
↓                   ↓
有手术            无手术
    ↓                   ↓
ADRG-B           ADRG-A
    ↓                   ↓
合并症评估          合并症评估
    ↓                   ↓
DRG              DRG
```

## 权重计算

### 公式

```
权重 = 该 DRG 组平均费用 / 全部 DRG 组平均费用
```

### 示例

| DRG | 描述 | 权重 |
|-----|------|------|
| ES23 | 呼吸系统肿瘤，伴严重合并症 | 3.5 |
| FB23 | 冠脉支架置入，伴严重合并症 | 4.2 |
| IC13 | 心力衰竭，伴中等合并症 | 1.2 |
| WB13 | 剖宫产，伴中等合并症 | 0.9 |
