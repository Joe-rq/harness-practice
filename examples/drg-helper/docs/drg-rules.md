# DRG 分组规则

## 概述

DRG（Diagnosis Related Groups，诊断相关分组）是一种患者分类方法，用于医疗服务绩效评价和费用管理。

## 分组逻辑

### 1. 主要诊断分类 (MDC)

按 ICD-10 首字母分类：

| 前缀 | MDC 编码 | 分类 |
|------|----------|------|
| A-B | 01 | 传染病 |
| C | 02 | 肿瘤 |
| D-E | 03-04 | 内分泌/血液 |
| F-G | 05-06 | 精神/神经 |
| H-I | 07-08 | 循环/呼吸 |
| J-K | 09-10 | 消化/肝胆 |
| L-M | 11-12 | 肌肉/皮肤 |
| N | 13 | 泌尿 |
| O | 14 | 产科 |
| P | 15 | 新生儿 |
| R | 17 | 症状体征 |
| S-T | 18-19 | 损伤/中毒 |

### 2. 邻近 DRG (ADRG)

根据是否有手术/操作：

| 情况 | ADRG 后缀 |
|------|-----------|
| 无手术/操作 | B |
| 有手术/操作 | C |

### 3. DRG 分组

根据合并症/并发症 (CC) 等级：

| 等级 | 后缀 | 说明 |
|------|------|------|
| 无 CC | 1 | 无合并症 |
| 轻度 CC | 2 | 轻度合并症 |
| 中重度 CC | 3 | 严重合并症 |

## 权重计算

权重反映 DRG 组的相对资源消耗：

```
权重 = 该组平均费用 / 全部组平均费用
```

示例：
- DRG 001: 权重 2.5（高费用）
- DRG 101: 权重 0.8（低费用）
